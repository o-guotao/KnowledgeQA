# 生成层 judge 校准记录（2026-10-12）

## 校准方法

对基线实验前 17 题（q01-q17）做逐条人工抽检：核对论断抽取质量、支持判定、相关性理由、
上下文相关/召回判定与检索实际结果的一致性。明细见
`backend/eval/results/baseline/calibration_review.md`。

## 首轮抽检结论（校准前）

| 指标 | 结论 |
|---|---|
| 忠实度 | 论断抽取原子化、判定准确，17/17 无误判 |
| 答案相关性 | **发现系统性偏差**：judge 用资料外世界知识扣分（q14"未说明国家 5%-12% 范围"判 0.7） |
| 上下文相关性 | 0.2~0.4 分布与 precision@K（0.26）一致，逐块判定合理 |
| 上下文召回 | 论断拆分粒度与参考答案复杂度吻合，覆盖判定正确 |

## 校准措施（judge.py 答案相关性 prompt 修订）

1. 不得因回答未包含资料之外的信息（行业惯例/法规背景/国家标准）而扣分
2. 回答中补充的、与问题相关的资料内信息不算冗余
3. 只有夹带与问题无关的内容时才按 0.7 档扣分

## 复跑验证（校准后）

- q14：0.7 → 1.0（外部知识误扣分消除）
- q01/q03：0.7 → 1.0（资料内相关补充不再误判冗余）
- q09/q17：保持 0.7，人工复核判罚正确（q09 问调薪晋升夹带年终奖系数表；q17 问发放时间夹带计算方式，确属无关内容）

## 已知行为（记录在案，不视为缺陷）

- **忠实度从严**：逻辑蕴含但未明确陈述的论断可能判不支持（q09："A 或 S 均可计入"是对
  "A 及以上"的合理推断，被判不支持 → 0.8）。保守取向，倾向低估忠实度而非高估。
- 四项指标在检索满分（recall=100%）时上下文召回自然饱和为 1.0，区分度主要体现在
  检索退化实验（如 iter02-nohybrid）与生成参数实验上。
