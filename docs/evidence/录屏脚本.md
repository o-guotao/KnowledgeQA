# 两分钟录屏脚本

> 目标：一条过展示 登录 → 上传 → 入库 → 流式问答 → 引用回跳 → 工具确认 → 停止 → 失败态 → 配额角标。
> 建议 1080p，语速正常，全程约 120s。录前准备：栈已启动、演示账号可登录、4 篇样例文档本地备好、一份临时调低 TASK_TIMEOUT_SECONDS 的 worker。

| 时间 | 画面 | 动作 / 解说 |
| --- | --- | --- |
| 0:00–0:10 | 登录页 | 「这是一个带权限的内部知识问答系统」输入 demo/demo1234 登录 |
| 0:10–0:30 | 侧边栏文档区 | 上传 4 篇样例文档，状态徽标 排队中→切分中→已入库；「上传后由任务表异步切分并向量化」 |
| 0:30–0:55 | 对话区 | 提问「报销必须在多少天内提交？标准是什么？」展示打字机流式输出与引用角标；「回答由服务端 SSE 代理模型，前端不接触密钥」 |
| 0:55–1:05 | 引用面板 | 点击 [1] 角标，右侧滑出原文并高亮；「引用可点回原文出处」 |
| 1:05–1:25 | 工具确认弹窗 | 提问「把产品FAQ.md 从知识库删掉」→ 模型发起 tool_call → 弹窗展示参数 → 点击拒绝后再确认一次执行；「敏感工具必须人工确认，操作留痕」 |
| 1:25–1:35 | 对话区 | 再次提问并点击停止按钮；「可随时停止生成」 |
| 1:35–1:45 | 失败态 | （断网或停 backend 演示）红色失败卡片 + 重试；「超时与异常都有降级失败态」 |
| 1:45–2:00 | 配额角标 + 终端 | 展示左下角 token/费用角标；切到终端 `grep traceId` 拉一条全链路日志收尾；「全链路 traceId 与费用统计，生产态开箱即用」 |

备选镜头（时间富余）：`psql` 展示 dead 状态任务一行，说明死信机制。
