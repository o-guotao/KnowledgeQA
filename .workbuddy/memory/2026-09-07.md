# 2026-09-07

## 完成 P0（生产可用底线）五项

基于 `docs/功能规划.md` 的 P0 清单，全部实现并验证。

### 1. embedding 抽象化（services/embeddings/ 包）
- `base.py`：EmbeddingBackend 协议（embed_texts / dim / is_semantic）
- 四后端：fastembed（本地 BGE）、openai（OpenAI 兼容 embedding API）、sentence_transformers（本地 torch）、hash（无语义降级，仅开发）
- `__init__.py` 工厂 `get_embedding_backend()` 单例 + `verify_embedding_ready()` 启动校验
- 关键设计：fastembed 懒加载，构造不暴露 onnxruntime 问题，真实可用性由 verify_embedding_ready 实际调用一次 embed 判定；Python 3.14 下 fastembed 崩 → development 自动降级 hash，production fail fast
- config.py 新增 EMBEDDING_BACKEND / OPENAI_EMBEDDING_* / ALLOW_HASH_EMBEDDING / ENVIRONMENT
- embedding.py 改为薄壳委托抽象层，调用点（worker/chat.py）零改动

### 2. 重排序接入（services/rerank.py）
- FastEmbed TextCrossEncoder（BGE-reranker-base），懒加载
- rag.py retrieve：RERANK_ENABLED 时召回 top_k*multiplier 候选 → cross-encoder 精排取 top_k
- chat.py 传 query_text 给 retrieve
- 重排失败内部降级为粗排截断（记日志）
- config.py 新增 RERANK_ENABLED（默认 false，生产 Docker 可开）/ RERANK_MODEL / RERANK_CANDIDATE_MULTIPLIER=4

### 3. 禁用 hash 进生产（启动校验 fail fast）
- verify_embedding_ready 返回 (ok, msg)；生产环境非语义后端或调用失败返回 False
- main.py startup：production 校验失败 raise fail fast，development 降级 hash 仅警告
- worker/main.py 启动同样校验（worker 是实际执行 embedding 的进程）

### 4. HTTPS + 域名（deploy/nginx/）
- nginx.conf：HTTPS 反代（前端静态 + /api 反代 + SSE 关缓冲），HTTP 跳 HTTPS，安全头，ACME 挑战路径
- setup-https.sh：certbot webroot 申请证书 + envsubst 渲染配置 + 启动 production profile
- docker-compose.yml 加 nginx 服务（profile: production）

### 5. 数据备份策略（scripts/ + docs/backup-restore.md）
- backup.sh：pg_dump（Postgres）+ MinIO tar + .env 快照 + MANIFEST
- restore.sh：停 backend/worker → 恢复 Postgres + MinIO → 重启（有确认提示）
- backup-restore.md：策略/定时 cron/异地加密/恢复演练/SQLite 本地备份/证书续期/RPO-RTO
- 注意：backup 服务不能做成 compose 服务（容器内无 docker CLI），backup.sh 是宿主机脚本
