## 召回评测（2026-09-08 下午）

用 conda langgraph 环境（Python 3.13，已装 fastembed 0.8.0）跑真实 BGE embedding 召回评测：
- 新建 `eval/run_recall_eval.py`（独立召回评测，只测召回不需 LLM/后端）
- 58 chunks（4 企业文档+3 干扰文档，chunk_size=128），标准 30 句 + 难句 10 句（questions_hard.jsonl）
- **发现并修复生产 bug**：`rerank.py` 的 fastembed 0.8 API 是 `rerank(query, documents)` 不是 `rerank(pairs)`，修复前全部 fallback（rerank 失效）
- 结果（报告见 `docs/evidence/混合检索与重排评测报告.md`）：
  - recall 全 100% 饱和（BGE 中文对企业制度召回极强，评测集难度不足）
  - 提升在 MRR：rerank 标准句 0.983→1.000（+0.017）、难句 0.900→0.925（+0.025）
  - hybrid 单独用 MRR -0.022（关键词噪声），需 rerank 配合；rerank 修正噪声（L3 文档外发 rank3→1）但也有个别误判（忘记打卡 rank2→4）
- 结论：rerank 收益最确定（RERANK_ENABLED=true 建议生产开启），混合检索必须配重排
