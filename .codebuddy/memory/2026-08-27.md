- 本机：Python 3.14.6（asyncpg/pydantic 旧 pin 无 wheel，**不要本地 pip install 后端依赖**，用户已拒绝过一次）、Node 24、无 Docker
- 后端本地验证仅限 `python -m compileall`（全通过）；运行时验证需用户 `docker compose up`（Dockerfile 用 python:3.12-slim 避开 3.14 兼容问题）
