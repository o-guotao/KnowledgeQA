# 文档预览（文本与图片 PDF）

## Goal

在文档列表对任意文档打开预览：有文字层的内容（.txt/.md、PDF 提取文本）可读文本；纯图片 PDF 也能逐页看到页面内容。预览只读且鉴权，避免把后台错误（如图片 PDF）变成"不可见"的黑盒。

## Requirements

1. 后端提供带鉴权的文档内容接口：按 document_id 取本人文档的原始字节（MinIO）或提取文本；txt/md 返回文本，PDF 按策略区分"提取文本可用"与"需逐页渲染"。
2. 前端在文档列表/详情提供预览入口（模态/抽屉），展示文本或图片型 PDF 的逐页渲染。
3. 图片型 PDF 逐页渲染：无需 OCR，仅可视化页面；方案权衡（后端渲染 PNG vs 前端 pdf.js）在设计阶段定。
4. 与 `09-07-batch-upload-validation` 联动：图片型 PDF 上传后进入「不可检索」终态并保留原文件，预览对其逐页渲染是主要查看手段；对 ready/failed 等历史文档同样可预览。预览按"任意状态的本人文档 + 原始字节"设计，不耦合特定状态。

## Acceptance Criteria

- [ ] 对 .txt/.md 与有文字层 PDF：可看到文本内容。
- [ ] 对纯图片 PDF（如历史 failed 文档）：可逐页查看页面渲染。
- [ ] 非本人/不存在文档访问返回 404/403，预览无越权。
- [ ] 文档删除后预览内容不可再访问。
- [ ] 打开/关闭预览不影响列表与轮询状态。

## Out of Scope

- PDF 内文字搜索/高亮、注释编辑。
- 在线编辑上传文件。

## Open Decisions

- 渲染技术选型（pdf.js 浏览器端 vs 后端 pypdfium2 出 PNG）为设计取舍，非产品决策，在设计阶段定。
