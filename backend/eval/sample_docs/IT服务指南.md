# IT 服务指南

## 设备申领

新员工入职当天可领取标准办公套装：MacBook Air（M3）或 ThinkPad X1 二选一、27 寸显示器一台、键鼠套装与扩展坞。设备归公司所有，离职时须归还。

设备每 3 年可申请换新一次；出现非人为故障的，随时可至 3 层 IT 服务台更换备机，备机最长借用 30 天。

## 工单与 SLA

IT 工单通过服务台系统提交，按紧急程度分级响应：P1 全员不可用，15 分钟内响应，2 小时内恢复；P2 部门级阻塞，30 分钟内响应，8 小时内解决；P3 个人问题，4 小时内响应，3 个工作日内解决。

VPN、邮箱、即时通讯账号类问题可走"极速通道"，平均处理时长 20 分钟。

## 标准软件清单

默认安装：办公套件、企业微信、Chrome、VS Code、Docker Desktop。设计岗位可申请 Figma 与 Adobe 全家桶 license，按季度采购审批。

禁止安装盗版软件与 P2P 下载工具；特殊软件需求提交工单说明用途，安全评估 2 个工作日内反馈。

## 打印与会议

打印默认双面黑白，彩色打印需在文印室刷卡并计入部门成本，单价每页 0.5 元。会议室投屏统一使用无线投屏协议，访客可使用 HDMI 转接线，服务台常备 5 根。
