# 公司食堂下周菜单（行政部发布）

## 周一

早餐：豆浆、油条、茶叶蛋、小米粥、咸菜。午餐：红烧排骨、宫保鸡丁、清炒时蔬、番茄蛋汤、米饭、酸奶。晚餐：糖醋鱼块、麻婆豆腐、蒜蓉油麦菜、紫菜蛋花汤。

## 周二

早餐：牛奶、全麦面包、煎蛋、燕麦粥。午餐：土豆牛腩、鱼香肉丝、手撕包菜、冬瓜排骨汤、杂粮饭。晚餐：回锅肉、酸辣土豆丝、清炒西兰花、银耳莲子羹。

## 周三

早餐：馄饨、煮玉米、卤蛋、紫米粥。午餐：香菇滑鸡、青椒腊肉、蒜蓉生菜、萝卜牛腩汤、米饭、香蕉。晚餐：红烧狮子头、干煸豆角、上汤娃娃菜、豆腐羹。

## 周四

早餐：绿豆粥、肉包、煎饺、拌黄瓜。午餐：咖喱鸡块、木须肉、清炒莴笋、玉米排骨汤、二米饭。晚餐：酸菜鱼、肉末茄子、蚝油生菜、南瓜粥。

## 周五

早餐：皮蛋瘦肉粥、花卷、咸鸭蛋、拌海带丝。午餐：红烧带鱼、京酱肉丝、蒜蓉菠菜、酸辣汤、米饭、苹果。晚餐：啤酒鸭、地三鲜、清炒空心菜、疙瘩汤。

## 温馨提示

每周三提供低脂轻食窗口，需要提前一天在行政系统预订。对食材过敏的同事请提前告知食堂管理员。周五下午茶提供当季水果和点心，凭工牌领取。
